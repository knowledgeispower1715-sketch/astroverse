###   BREAKING CHANGES

* **native:** failed or cancelled native UI scenarios now return typed errors with the collected report in partial_observation instead of successful reports containing failed or cancelled steps.
* **providers:** binary_session candidate availability can be unknown during owner finalization. Consumers must handle this state; the internal session status API is now asynchronous.
* **native:** Swift symbol address can now be null when the provider has no location. Clients consuming swift_symbols must handle an unknown address. The original provider value is retained in optional evidence.reported_address.
